# Construct's Eye: Initiative Tracker Project
Simple Initiative tracker for DND in C.

## MVP Requirements
- [X] Can add entities and sort them by initiative.
- [ ] Can delete entities mantaining initiative order.
- [ ] Can go forward and backwards in initiative order. 
- [ ] Terminal User Interface.
- [ ] For each entity shows its HP, AC, Initiative and Name.
- [ ] Has a no HP optional mode.
- [ ] Supports adding multiple of the same entity.
- [ ] Can generate random initiative.
- [ ] Can update any character HP.
- [ ] Can begin and end a combat encounter.
- [ ] Shows current round number
- [ ] Has victory command (with sound)
